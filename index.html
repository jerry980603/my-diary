    ☁️ GitHub 同步設定

    用一個私人 repo 當雲端資料庫，手機和電腦就能共用同一本日記。
    🔒 權杖只存在這台裝置的瀏覽器裡，不會傳給任何第三方；日記內容只會傳到你自己的 repo。
    ⚠️ 文字內容會同步；附件（照片檔案）留在各自裝置，因為檔案太大不適合放 GitHub。
    怎麼建立 repo 和 token？（點開看步驟）
    1. 到 GitHub 按 New repository，名稱例如 my-diary-data，務必選 Private，建好即可（可以是空的）。
    2. 到 Settings → Developer settings → Personal access tokens → Fine-grained tokens，按 Generate new token。
    3. Repository access 選 Only select repositories，只勾剛剛那個 repo。
    4. Permissions 裡把 Contents 設成 Read and write（其他都不用給）。
    5. 設定到期日（例如 1 年），產生後把 token 複製貼到上面欄位。
    6. 手機上打開同一個網站，填一樣的三個欄位，就會同步同一本日記。
